# AI Data Analyst Agent

## About the Project
AI Data Analyst Agent is an AI-powered automation project built using n8n and OpenAI GPT-5-mini. It helps answer user queries, maintain conversation memory, store information in Google Sheets, and automate email communication through Gmail.

## Features
- Answers user queries using AI.
- Maintains conversation history using Simple Memory.
- Connects with Google Sheets to store information.
- Uses Gmail to automate email communication.
- Reduces repetitive manual tasks and saves time.

## Technologies Used
- n8n
- OpenAI GPT-5-mini
- Simple Memory
- Google Sheets
- Gmail

## Workflow
1. User sends a message through the chat interface.
2. AI processes the query using GPT-5-mini.
3. Simple Memory maintains conversation context.
4. Google Sheets stores relevant information.
5. Gmail handles email communication.

## Benefits
- Saves time and effort.
- Reduces repetitive work.
- Improves workflow efficiency.
- Provides AI-powered assistance.
